# 30个可变选题种子

以下均为原创创意起点，不是来源账号已发布作品，也未经效果验证。按人设改写动机、行动和结局，不给用户只换物种的标题清单。

| 编号 | 生活触发 | 可发展的事件机制 | 情绪/制作提示 |
|---|---|---|---|
| S01 | 晚归灯亮 | 省钱角色为别人破一次自己的规则 | 被惦记；单室内 |
| S02 | 忘记带伞 | 嘴硬角色把唯一的伞送出，另一方回头接它 | 互相照顾；避复杂淋雨动作 |
| S03 | 安静需求 | 热情角色学会陪伴而不说话 | 关系成长；反应镜头 |
| S04 | 生日忘记 | 主角以为无人记得，发现礼物是一个解决旧麻烦的物件 | 用具体细节替代万能惊喜 |
| S05 | 不想接语音 | 角色发明礼貌拒绝法，反而给自己增加解释任务 | 嘴替；问答或独白 |
| S06 | 聚会提早走 | 两个角色各自装作有事，门口遇见一起松口气 | 社交共鸣；少场景 |
| S07 | 发薪分账 | 想买礼物却给自己设了过严预算 | 愿望与现实，不展示真实理财建议 |
| S08 | 带饭被夸 | 平时不自信的角色开始主动分享做法 | 被认可；成品代替烹饪动作 |
| S09 | 第一次休假 | 无法停止“上班式安排”的角色给休息列考核 | 自我松绑；桌面小道具 |
| S10 | 周末计划取消 | 扫兴的小意外让两个角色获得更喜欢的相处方式 | 不必强反转 |
| S11 | 整理旧物 | 急着扔东西的角色发现某物承载对方的记忆 | 道具回调 |
| S12 | 修一把椅子 | 两人争谁更专业，最后各解决一半问题 | 互补；准备/结果镜头 |
| S13 | 做一个礼物 | 平时粗心者记住接收者一个冷门偏好 | 能力反转 |
| S14 | 第一次摆摊 | 原计划卖产品，第一位客人却需要一项简单帮助 | 被需要；不把剧情收入当真实 |
| S15 | 照顾新植物 | 两人用相反方法照料，学会先观察再行动 | 克制与合作；生长用分日镜头 |
| S16 | 约定比赛 | 争胜角色第一次主动放弃小胜帮助同伴 | 选择体现人设变化 |
| S17 | 新邻居搬来 | 主角误把对方的生活习惯当成不友好 | 陌生到理解 |
| S18 | 帮社区跑腿 | 接受太多任务的角色学会说一次“不” | 边界与尊严 |
| S19 | 被冤枉弄坏物品 | 角色选择先修复关系再解释细节 | 不能用无因突然真相解决 |
| S20 | 公共座位 | 外来角色总站着，后来被自然留了一个位置 | 归属；避免复制原案例事件 |
| S21 | 老朋友来访 | 新旧朋友对主角了解不同，引出新的性格侧面 | 群像谨慎增加 |
| S22 | 离开熟悉地方 | 主角以为带走物件就能留住记忆，最后留下约定 | 阶段性季终 |
| S23 | 途中绕路 | 理性搭档坚持最短路线，意外学会容纳慢一点 | 关系推进；可用地图道具 |
| S24 | 计划资源不足 | 两人对“删掉哪个愿望”意见不同，重新定义目标 | 长期目标的新选择 |
| S25 | 第一次当负责人 | 平时吐槽者发现做决定的代价 | 角色交换 |
| S26 | 采访：最近长大了吗 | 回答落在一个很小但具体的行为变化 | 单场景问答 |
| S27 | 采访：最贵的东西 | 回答不落价格，而落等待或承诺 | 不空喊鸡汤 |
| S28 | 采访：怎么和好 | 角色演示一件笨拙的日常小事 | 可用画外提问 |
| S29 | 小型救援 | 平时被照顾者发现只有自己能完成的小任务 | 反向守护；控制动作规模 |
| S30 | 旧承诺兑现 | 前集不起眼的约定在普通一天被认真完成 | 季播回调；需明确前集ID |

品牌版可将物件、任务或使用场景映射到实际产品，但先确认真实产品能力；不反过来为植入杜撰功效。热点版只借具体情绪或生活处境，事实热点须查证。
